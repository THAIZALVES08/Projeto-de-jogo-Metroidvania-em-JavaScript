# Projeto-de-jogo-Metroidvania-em-JavaScript 

Este foi um projeto realizado em grupo, desenvolvido com base no tutorial disponível no YouTube: https://youtu.be/iM1iSvloMlo?si=fcVbfrPBMdRsgsPz.

Apesar de o tutorial ser completo e bem explicado, enfrentamos diversas dificuldades ao longo do desenvolvimento. Utilizamos a Inteligência Artificial como ferramenta de apoio na identificação e correção de alguns erros de sintaxe, além de outras dificuldades encontradas durante a implementação.

Foi um projeto muito importante para o meu aprendizado, principalmente por proporcionar uma experiência prática de trabalho em equipe. Também me ajudou a compreender melhor como colaborar com outras pessoas no desenvolvimento de um mesmo código, dividindo tarefas, solucionando problemas em conjunto e aprendendo com as dificuldades encontradas durante o processo.
